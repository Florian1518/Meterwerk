# Mobile und PWA

Meterwerk ist eine responsive Web-App/PWA, keine native iOS- oder Android-App. Browserseitig kann sie zum Startbildschirm hinzugefügt werden. Dashboard, Zähler, Readings, Alarme und zugewiesene Einsätze sind mobil nutzbar. Bei Offline-/Reconnect-Problemen warten, Verbindung prüfen und den Status erneut laden; eine vollständige lokale Offline-Synchronisation ist nicht garantiert.
