# Analytics

Analytics zeigt Verbrauch, Lastprofile, Kosten, Vergleiche/Benchmarks, Anomalien und Forecasts. Zeiträume und Berichtzeitzone sichtbar prüfen. Forecasts sind modellbasierte Prognosen und keine garantierten zukünftigen Werte. Fehlende oder geschätzte Readings können Ergebnisse beeinflussen; Datenqualität und Quellen beachten.
