# New-Tenant-Checkliste

- [ ] Tenant und Tenant Admin angelegt
- [ ] Benutzer/Rollen/Property-Grants geprüft
- [ ] Properties, Buildings, Units und Meter erfasst
- [ ] Devices/Gateways/Profile geprüft
- [ ] Dashboards, Reports, Rules und Alarme geprüft
- [ ] API/Webhooks nur bei Bedarf eingerichtet
- [ ] Export, Audit und Supportweg geprüft
