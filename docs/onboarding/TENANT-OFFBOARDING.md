# Tenant-Offboarding

Zugänge und Sitzungen prüfen, Benutzer deaktivieren, API Keys widerrufen/rotieren, Webhooks entfernen oder deaktivieren, Device-/Gateway-Credentials kontrolliert auslaufen lassen, Datenexport bereitstellen, offene WorkOrders/Supportfälle dokumentieren, Backups/Audit und konfigurierte Retention prüfen. Löschung nur über tatsächlich implementierte Funktionen und freigegebene Aufbewahrungsregeln; keine gesetzlichen Fristen erfinden.
